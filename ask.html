Ask questions about your documents.

    /how-it-works

    An agent that reads before it answers.

    1. Read

      Text is pulled from every page, slide, sheet and paragraph, keeping track of where it came from.

    2. Chunk

      The text is split into overlapping passages of about 700 characters, so no fact is cut in half.

    3. Embed & store

      Each passage becomes a vector (bge-small) and is saved in a vector database inside your browser, so documents are ready next time.

    4. Retrieve & re-rank

      Each question runs keyword and vector search together, then a cross-encoder re-ranks the candidates by how well they answer it.

    5. Answer

      A reading model picks the exact answer and the sentence it came from. Load a chat model for full written answers with citations.

    Your files stay with you

    Everything runs on your device. Your library is stored only in this browser; remove a file with × to delete it.

    Best for facts and explanations

    Ask who, what, when or how much, what a slide says, or for a summary. It isn't built for heavy calculations across large spreadsheets.

    Works on any modern browser

    Exact answers run anywhere. The chat model needs WebGPU, available in recent Chrome and Edge on a computer.

    /self-hosted · for teams

    The same agent, on your own server.

    For a shared knowledge base, we run the team edition of this assistant inside your network. Documents are indexed once, everyone asks questions in a chat window, and no API keys or cloud AI services are involved.

    Index once, ask any time

    PDFs are split into passages, embedded with a local model and kept in a Chroma vector store. Re-index when documents change.

    An agent that checks first

    A LlamaIndex ReAct agent must search the knowledge base before every answer, and says so when the answer isn't in your documents.

    Fully local models

    Llama 3.2 for answers and nomic-embed-text for search, both served by Ollama. Ships as a Docker image with a Gradio chat UI.

    # pull the local models once
ollama pull llama3.2:3b
ollama pull nomic-embed-text

# index the PDFs in docs/, then start the chat UI on :8080
python ingest.py
python app.py
