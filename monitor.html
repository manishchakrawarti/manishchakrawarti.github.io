        /in-production
        
    What runs in your cloud.
    
        
    In production the same engine writes to BigQuery tables in your project, and an AI agent picks up the failures the rules can't fix.
    
      
    
      
    
        
    Wrap any Python job
    JobMonitor records every run, step, warning, retry and error to ops_monitoring, checks each good run against its history, and alerts on-call. Killed jobs show up as runs that never finished.
    
        
    Rule-based healer
    Schema drift is diffed against the live table. Lossless fixes run after a dry run; anything that rewrites data is stored for approval.
    
        
    Log-analysis agent
    Every 15 minutes, Claude investigates new failed runs with read-only tools and proposes SQL. The SQL guard decides what may run.
